BOOKMARK SEPARATOR

Drag these to your bookmarks bar to create visual separators.

How it works

Drag a separator to your bookmarks bar.

Each drag generates a unique URL with a random identifier, allowing
you to create multiple separators of the same type without browser
conflicts.

The page displays ?vert or ?horz in the URL with a unique hash fragment.
When you drag, the page's favicon is updated and cached by the browser
for that specific URL pattern.

When switching between separator types (vertical to horizontal or vice
versa), the page generates a final unique URL for the previous type
before switching. This ensures already-created bookmarks maintain their
correct icons.
