  1. Show the bookmarks bar Press Ctrl + Shift + B in Chrome, Edge or Brave.
  2. Drag a separator onto the bar Drop it between the bookmarks you want to split.
  3. Hide the name if one shows up Right-click the new bookmark, choose Edit, clear the name and save, so only the icon is left.
  4. Repeat as often as you like Every drag creates a new unique link, so separators never replace each other.

Icon missing? Click the separator once. The page opens and puts its icon back, then you can close the tab.

How it works

Each drag generates a unique URL with a random identifier, allowing you to create multiple separators of the same style without browser conflicts.

The page shows the style in the URL (for example ?vert or ?dot) with a unique hash fragment. When you drag, the page's favicon is updated and cached by the browser for that specific URL.

When switching between styles, the page first moves to a final unique URL for the previous style before switching. This ensures bookmarks you already created keep their correct icons.
